Servicio

Consulta de permiso de circulación

Escriba la patente de un vehículo para ver si su permiso de circulación está vigente, en qué comuna se pagó y cuánto. Sirve también para patentes provisorias de automotora.

Sin guiones ni puntos. Admite los dos formatos: dos letras y cuatro dígitos, o cuatro letras y dos dígitos. Para una provisoria, PR y cuatro dígitos.

De dónde salen estos datos

La pantalla no tiene una base propia

Este servicio consulta la API de permisos de circulación por la misma interfaz pública que usaría el sistema de un municipio o el de una institución que fiscaliza. No tiene acceso privilegiado ni una copia paralela del registro.

Qué consultaOperación de la API
Los datos del vehículoGET /vehiculos/{patente}
Sus permisos por año, con la comuna que los recaudóGET /vehiculos/{patente}/permisos
Los permisos de una patente provisoriaGET /permisos-provisionales/{patente}

La comuna viaja como código, no como nombre. Cada permiso identifica a la institución recaudadora con su Código Único Territorial —13101, no SANTIAGO—, que es lo que permite cruzar esta información con cualquier otra del Estado sin adivinar. Es el estándar del CUT usado por otro intercambio, que es exactamente para lo que existe. La entrada de wiki de este servicio, con lo que cambió respecto de la colección de referencia, está en permisos de circulación.
