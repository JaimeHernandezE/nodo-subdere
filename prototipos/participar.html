Cómo participar

Tres caminos, según quién sea usted

Hay dos situaciones que conviene no mezclar: construir y practicar, que no le pide permiso a nadie, y trabajar con datos de un municipio, que sí. Cómo funciona por dentro está en Qué es el nodo.

Todavía no existe. La idea es que cada servicio publicado tenga una zona de práctica con datos inventados, donde cualquiera pueda construir sin firmar nada. Para trabajar con los datos de un municipio hace falta un convenio con SUBDERE, y ese convenio habilita una credencial a nombre de ese municipio. Hoy no hay ninguna zona de práctica funcionando.

El nodo conecta sistemas, no personas. No tiene pantalla para subir planillas: para eso ya existen los formularios de las plataformas que reciben.

MUNICIPIOS

Quiero usar el nodo

No necesita cambiar de sistema. Si el suyo ya cumple lo publicado, conversa directo con el nodo; para trabajar con datos reales hacen falta el convenio y la credencial. También puede usar solo una parte del SGM —por ejemplo Adquisiciones—, que siempre viene con la base común. Si no tiene ningún sistema, el camino es el SGM.

PROVEEDORES

Quiero conectar mi sistema

Lo publicado es público y cualquiera puede construir a partir de ahí. La idea es que se pueda practicar con datos inventados sin firmar nada. Para trabajar con datos de un municipio hace falta el convenio de ese municipio con SUBDERE. La pantalla del propio SGM entra por la misma puerta que usted: nadie tiene atajos.

INSTITUCIONES

Recibo información de municipios

En vez de recibir envíos sueltos de trescientos y tantos municipios, recibe de uno solo. No tiene que cambiar nada de su lado: el nodo le entrega en el formato que usted ya acepta hoy.
