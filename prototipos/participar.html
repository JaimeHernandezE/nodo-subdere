Cómo participar

Tres caminos, según quién sea usted

El nodo distingue dos planos que conviene no mezclar: construir y probar, y operar con datos de un municipio. Ambos pasan por la Plataforma de Control. El detalle del flujo está en Qué es el nodo.

Diseño previsto. Cada endpoint publicado tendrá un sandbox con el mismo contrato que producción y datos sintéticos, sin convenio. Para operar con una municipalidad hace falta un convenio con SUBDERE; ese convenio habilita un identificador de cliente (credencial de sistema) con el que se obtienen tokens y se usa la plataforma. Hoy ningún sandbox está desplegado.

El nodo conecta sistemas, no personas. No tiene pantalla para subir planillas — para eso ya existen los canales de carga de las plataformas que reciben.

MUNICIPIOS

Quiero usar el nodo

No necesita cambiar de sistema. Si el suyo implementa el estándar, conversa con la Plataforma de Control. Para datos reales: convenio con SUBDERE e identificador de cliente. También puede consumir por módulo —por ejemplo solo Adquisiciones—, siempre con el core de plataforma, que no se elige. Si no tiene sistema, el camino es el SGM.

PROVEEDORES

Quiero conectar mi sistema

El estándar es público. El diseño prevé construir y probar en sandbox con datos sintéticos, sin convenio. Para operar con datos de un municipio hace falta el convenio de ese municipio con SUBDERE (y el identificador de cliente asociado). El frontend del SGM y un sistema municipal entran por la misma puerta: no hay privilegios.

INSTITUCIONES

Recibo información de municipios

En vez de recibir cargas manuales de cada municipio por separado, puede recibir de una sola contraparte. No tiene que cambiar su sistema: el nodo entrega en el formato que usted ya acepta.
