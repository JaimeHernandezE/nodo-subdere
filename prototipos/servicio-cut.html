Servicio

Buscador de códigos territoriales

Escriba el nombre de una comuna, provincia o región para obtener su Código Único Territorial. O escriba un código para ver a qué lugar corresponde. Funciona en las dos direcciones con el mismo campo.

Dos dígitos se leen como región, tres como provincia y cinco como comuna. Los ceros a la izquierda son parte del código, pero si los omite igual se encuentra.

De dónde salen estos datos

La pantalla no tiene una lista propia

Este buscador consulta la API de Códigos Únicos Territoriales por la misma interfaz pública que usaría el sistema de un municipio o el de un proveedor. No tiene acceso privilegiado ni una copia paralela de la lista: si la API cambia, esta pantalla cambia con ella.

Qué consultaOperación de la API
La lista de regiones, provincias y comunas, al abrir la páginaGET /regiones · GET /provincias · GET /comunas
El detalle de una comuna con su provincia y regiónGET /comunas/{id}/full
El detalle de una provincia con su regiónGET /provincias/{id}

Un detalle que esta pantalla corrige a mano. La API entrega los códigos como número entero, así que Iquique llega como 1101 y no como 01101. Acá se muestran con sus ceros a la izquierda, que es la forma canónica. Que cada cliente tenga que rellenarlos por su cuenta es una de las observaciones al contrato: está en la entrada de wiki del CUT.
