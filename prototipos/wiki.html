Todo lo que hay que saber para usar el nodo

Los catálogos muestran qué hay. Aquí explicamos cómo se usa y por qué lo definimos así: desde pedirle un dato a una API hasta de dónde sale el código de cada comuna y qué ley nos obliga a cada cosa.

Está escrita para funcionarios municipales, proveedores y cualquiera que quiera conectar un sistema. Cuando aparece un término técnico, lo explicamos en la misma frase, y los que se repiten están en el glosario.

Cómo está ordenada

Cinco temas, una página para cada pregunta

El menú de la izquierda agrupa las páginas por tema. Cada enlace lleva a una página propia.

  • Usar el nodoCómo funciona un intercambio, cómo se usa una API, cómo conectar un sistema y cómo leer una ficha del catálogo.
  • IntercambiosUna entrada por cada intercambio del catálogo: cómo funciona, qué norma lo respalda y qué observamos en su contrato. El índice crece solo a medida que se publican.
  • Códigos y datos maestrosQuién define cada código que se intercambia, cómo se numera y cuáles faltan por definir.
  • Marco normativoLa ley detrás de cada exigencia, y si leímos el texto completo o solo una referencia.
  • ReferenciaEl glosario con las palabras que usamos en todo el sitio, y las decisiones de arquitectura que explican por qué está hecho así.
