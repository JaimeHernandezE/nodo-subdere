# Nodo SUBDERE — documentación

Documentación del Nodo SUBDERE: el punto único por el que un municipio entrega información a las instituciones que se la piden, y recibe constancia de lo entregado.

La maqueta HTML vive en [`prototipos/`](../prototipos/) y se publica en [GitHub Pages](https://jaimehernandeze.github.io/nodo-subdere/).
